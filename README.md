# House-Price-Prediction-Model-
This project focuses on building a machine learning model to predict house prices based on various features such as location, area, number of rooms, and other relevant factors. The goal is to analyze housing data and generate accurate price predictions using regression techniques.

Objectives--
Analyze housing data to identify key factors affecting price
Apply regression techniques for prediction
Compare performance of Linear vs Polynomial Regression
Visualize actual vs predicted results
Improve model accuracy through preprocessing and feature engineering

Project Workflow--
1. Data Preprocessing
Handling missing values (NaN → 0 or mean)
Converting categorical data into numerical format
Feature scaling (if required)
2. Exploratory Data Analysis (EDA)
Understanding relationships between variables
Visualizing trends using graphs
3. Model Building
Linear Regression
Polynomial Regression (to capture non-linear patterns)
4. Model Evaluation
R² Score
Mean Squared Error (MSE)
Visualization of Actual vs Predicted values
